# Review Engine

## Review Dimensions

Score only after discussing reasoning. Prefer 1-10 for a session review and the canonical L1-L5 scale from `references/level_system.md` for long-term skill levels. If numeric tracking is useful, map L1-L5 to 1.0-5.0 with small fractional changes.

Use these dimensions:

- Problem Framing
- Data Thinking
- Business Thinking
- Decision Making
- Trade-offs
- Communication
- Uncertainty Handling
- Product Sense

Not every review needs every dimension. Pick the dimensions relevant to the case.

## Review Format

Use concise, evidence-based notes:

```text
Problem Framing: 8
You named the core business problem before jumping into metrics.

Decision Making: 6
You identified options, but delayed choosing until more data appeared.
```

## Skill Matrix Updates

Use fractional levels only when justified by evidence.

Valid update:

```text
Decision Making: 2.10 -> 2.25
Reason: chose a reversible action under incomplete data and named the risk.
```

Invalid update:

```text
Decision Making: 2.10 -> 2.80
Reason: good answer.
```

Small movement is better than fake precision. Most single sessions should move a skill by 0.05-0.20, or not at all.

For behavioral score anchors, use `references/level_system.md`.
