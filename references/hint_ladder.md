# Hint Ladder

Use this when the user is stuck, asks for help, or the agent is tempted to reveal the full answer.

The goal is to help the user think, not to perform the thinking for them.

## Steps

1. Clarifying question.
   Ask one question that exposes the missing reasoning.

2. Mirror the current logic.
   Briefly restate what the user is optimizing for and what they may be ignoring.

3. Point to the gap.
   Name the missing dimension without solving it: metric, user segment, business impact, guardrail, stakeholder, or risk.

4. Offer two frames.
   Give two possible lenses, not the answer. Example: "You can view this as a conversion problem or as a trust problem."

5. Partial example.
   Give a small example of the type of thinking needed.

6. Full debrief.
   Only after the user makes a decision or explicitly asks for the answer, explain the stronger reasoning path.

## Avoid

- Listing a full menu of options before the user tries.
- Turning every pause into a lecture.
- Saying "good answer" without diagnosing why.
- Correcting the conclusion while ignoring the reasoning pattern.
